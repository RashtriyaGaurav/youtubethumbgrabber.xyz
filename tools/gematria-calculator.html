What is gematria?

Gematria is the practice of assigning a numerical value to each letter of an alphabet, then adding those values up to give a word or phrase a single total. It started in Hebrew scholarship — where letters already doubled as numerals — as a tool for finding numerical connections between words in religious texts. The same idea later appeared in Greek as "isopsephy," and, much more recently, in a range of informal English ciphers popularized online.

The 7 ciphers, explained

English gematria has no single agreed standard — different sites define ciphers with the same name differently. Here's exactly how each one works in this calculator, so you can check the math yourself.

Cipher How it's calculated
Ordinal A=1, B=2, … Z=26 — each letter's position in the alphabet, summed.
Reverse Ordinal A=26, B=25, … Z=1 — the alphabet counted backward.
Reduction Each letter's Ordinal value is reduced to a single digit by adding its digits together (K=11 → 1+1=2), then summed.
Reverse Reduction The same digit-reduction, applied to each letter's Reverse Ordinal value instead.
English Gematria (×6) Each letter's Ordinal value multiplied by 6 — A=6, B=12, … Z=156.
Jewish Gematria English letters mapped onto a Hebrew-style units/tens/hundreds table: A–I = 1–9, K–S = 10–90, T,U,X,Y,Z = 100–500, with J=600, V=700, W=900 as fixed exceptions.
Hebrew Gematria The original system (Mispar Hechrachi) — real Hebrew letters summed using their standard values, א=1 through ת=400.

A quick note

Gematria is a symbolic and interpretive practice, not a scientific or mathematical proof of anything. Two words sharing a total is a property of whichever cipher table you're using — this calculator reports the arithmetic accurately, but what you make of a match is a matter of tradition and personal belief.

Frequently asked questions

What is gematria?

A system that assigns a number to each letter of an alphabet, then sums them to give a word or phrase a total value.

Which cipher should I use?

Hebrew Gematria is the original, historically documented system. The English ciphers are modern adaptations with no single standard, so it depends on which tradition or online source you're comparing against.

Why do different calculators give different numbers for the same word?

English gematria isn't one historical system — different sites use different tables under similar names. This calculator states exactly how each cipher is defined.

Does a matching value between two words mean something?

That's a matter of interpretation and belief — this tool only reports the arithmetic.

Can I calculate real Hebrew words?

Yes — type Hebrew characters directly and the Hebrew Gematria result uses the standard Mispar Hechrachi values.
